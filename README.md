# 🎮 CodeAlpha Hangman Game

A simple console-based Hangman game developed using Python as part of my CodeAlpha internship tasks.

## 📌 Project Overview

This project is a command-line Hangman game where the player tries to guess a randomly selected word one letter at a time.

The player has a maximum of 6 incorrect guesses.

## ✨ Features

- Randomly selects a word from 5 predefined words
- Allows the player to guess one letter at a time
- Maximum of 6 incorrect guesses
- Displays the current progress of the word
- Keeps track of guessed letters
- Prevents repeated guesses
- Validates user input
- Displays win and game-over messages

## 🛠️ Technologies Used

- Python
- Random module
- Strings
- Lists
- While loops
- For loops
- If-else conditions

## 🎯 How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python IDE.
4. Run the following command:

```bash
python hangman.py
```
